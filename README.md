# YOLO TFLite Real-time Object Detection with Spatial Relationships

A real-time object detection system using YOLO TFLite models that can detect objects and identify spatial relationships between them (e.g., "glass on table", "pillow on bed").

## 🚀 Features

- **Real-time Object Detection**: Detects objects using YOLO TFLite models
- **Spatial Relationship Detection**: Identifies relationships like "object A on object B"
- **Live Camera Feed**: Processes webcam input in real-time
- **Confidence Scoring**: Shows detection confidence for each object
- **Visual Annotations**: Clear bounding boxes, labels, and relationship indicators
- **Periodic Processing**: Processes frames every ~n second for better accuracy
- **Debug Information**: Detailed console output for troubleshooting

## 📋 Requirements

- Python 3.7+
- Webcam (camera index 0)
- Required packages:
  ```bash
  pip install opencv-python tensorflow numpy
  ```

## 🛠️ Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Zendex011/object_detection.git
   cd object_detection
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Add your model file**:
   - Place your TFLite model file as `best_float32.tflite` in the project directory
   - Or update the `MODEL_PATH` in the script to point to your model

## 🎯 Usage

### Basic Usage

```bash
python run_pytorch_inference.py
```

### What to Expect

1. **Live Camera Feed**: The script opens your webcam and shows a live video feed
2. **Processing Indicator**: Shows "PROCESSING..." when analyzing a frame
3. **Detection Results**: Displays bounding boxes, object names, and confidence scores
4. **Spatial Relationships**: Shows relationships like "glass on table" in yellow text
5. **Console Output**: Detailed debug information about detections
6. **Object Tracking**: Track object over multiple frame

### Controls

- **Press 'q'** to quit the application
- **Wait for processing** - The system processes every 30 frames (~1 second)

## 🔧 Configuration

### Model Configuration

The script is configured for a YOLO model with:
- **Input size**: 640x640 pixels
- **Classes**: 84 object classes (bed, table, pillow, glass, chair, sofa, book, lamp, tv, cup, bottle, unknown,.........)
- **Output format**: Single tensor with shape (1, 16, 8400)

### Customizing Classes

Edit CLASS_NAMES in run_pytorch_inference.py to change class labels.

Detection Parameters

Confidence threshold: conf_threshold (default 0.2)

NMS threshold: iou_threshold (default 0.45)

Frame skip interval: detect_every_n_frames (default 5)

### Adjusting Detection Parameters

- **Confidence threshold**: Change `conf_threshold = 0.1` (lower = more detections)
- **Processing frequency**: Change `process_every_n = 30` (lower = more frequent processing)
- **NMS threshold**: Change `iou_threshold=0.45` in the `_nms` function call

## 🐛 Troubleshooting

### Common Issues

1. **No detections showing**:
   - Check if the model file exists and is correct
   - Lower the confidence threshold
   - Check console output for debug information

2. **Camera not opening**:
   - Ensure your webcam is connected and not used by other applications
   - Try changing the camera index in the script (0, 1, 2, etc.)

3. **Poor detection accuracy**:
   - Ensure good lighting
   - Make sure objects are clearly visible
   - Adjust confidence threshold
   - Check if your model was trained on similar objects

### Debug Information

The script provides detailed debug output including:
- Raw box coordinates from the model
- Coordinate transformations
- Confidence scores
- Detection counts at each processing stage

## 🔄 Model Conversion

If you have a PyTorch YOLO model (.pt file), you can convert it to TFLite using:

```bash
python convert_and_test.py
```

This will convert your PyTorch model to TFLite format and test it on a sample image.
